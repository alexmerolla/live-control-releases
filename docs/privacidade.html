Política de Privacidade

Esta política descreve o tratamento de dados no Live Control, aplicativo portátil para Windows desenvolvido por Alex Merolla. Contato: alexmerollap@gmail.com.

Dados acessados e finalidade

Ao conectar o Google, o aplicativo solicita https://www.googleapis.com/auth/youtube.readonly. Usa essa autorização para consultar informações do canal, identificar transmissões da conta autorizada e obter identificadores e informações necessários à seleção das lives de YouTube e Shorts.

Os conectores de chat processam mensagens, nomes de usuários, identificadores e horários das origens conectadas para apresentar o chat e interpretar comandos. Ao registrar um corte, o aplicativo mantém a origem, o autor, identificadores, horário, categoria, descrição e referências do arquivo local. Preferências, conexões e histórico permitem retomar o uso do aplicativo.

Onde os dados ficam

Configurações e histórico ficam no computador, no diretório de dados do usuário Windows. Credenciais salvas usam a proteção DPAPI do usuário Windows. Os vídeos são salvos nas pastas configuradas no OBS/Aitum; referências e miniaturas podem ficar no armazenamento local do Live Control.

O fluxo de login ocorre no navegador do Google. O Live Control recebe tokens de autorização, não a senha da conta Google. A permissão solicitada não autoriza publicar, editar ou apagar vídeos no YouTube.

Comunicação com serviços externos

As funções conectadas comunicam-se com Google/YouTube, Twitch e Kick. A atualização consulta o manifesto e baixa pacotes hospedados no GitHub. Prévias de transmissões, quando ativadas, podem carregar players de terceiros sujeitos às políticas desses serviços. O OBS e o Aitum recebem comandos de captura conforme a configuração do usuário.

O funcionamento descrito não inclui o envio automático de tokens, histórico ou vídeos a um servidor do desenvolvedor. Se você enviar um relato ou arquivo para suporte por e-mail, o conteúdo enviado será usado para responder e investigar o problema. Evite enviar senhas ou tokens.

Uso de dados Google

Os dados acessados pelo Google são usados para as funcionalidades de conexão e acompanhamento de transmissões solicitadas pelo usuário. Não são vendidos, usados para publicidade personalizada ou utilizados para treinar modelos de inteligência artificial. O uso e a transferência de informações recebidas das APIs Google obedecem à Política de Dados do Usuário dos Serviços de API Google, incluindo os requisitos de Uso Limitado.

Desconectar, revogar e excluir

Use Desconectar → YouTube / Shorts para desativar a integração e solicitar a remoção da autorização salva. A interface informa se a remoção ou gravação falhar. Desconectar preserva os cortes e referências da sessão.

Você também pode revogar o acesso do Live Control na página de conexões da sua Conta Google. Revogar o acesso no Google não apaga automaticamente arquivos locais.

Para apagar todos os dados locais do Live Control, feche o aplicativo e remova seu diretório de dados, normalmente %LOCALAPPDATA%\LiveControl. Isso remove configurações, credenciais e históricos de todos os perfis ali armazenados. Faça uma cópia do que deseja conservar antes. Vídeos nas pastas do OBS/Aitum e cópias externas precisam ser removidos separadamente. Se o diretório de dados foi personalizado, remova o diretório correspondente. Para orientação, contate o suporte.

Conservação e segurança

Preferências e históricos locais permanecem até sua exclusão pelo usuário; restaurar padrões não apaga contas nem histórico. O usuário controla o acesso ao computador e às cópias de segurança. A proteção de credenciais não impede o acesso por quem já tenha controle da sessão Windows.

Este site e políticas externas

Estas páginas não possuem formulários, publicidade, ferramentas de análise ou cookies adicionados pelo Live Control. A hospedagem no GitHub Pages pode processar informações técnicas de acesso conforme a Política de Privacidade do GitHub.

O aplicativo usa os Serviços da API do YouTube. Consulte também a Política de Privacidade do Google e os Termos de Serviço do YouTube.
